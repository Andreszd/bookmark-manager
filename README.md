# 📘 Bookmark Management

This project was developed for learning purposes. It uses Angular for the frontend and Express for the backend. Both are placed in a monorepo powered by Turborepo, which helps streamline development by:

Sharing common TypeScript types between frontend and backend

Running both projects simultaneously with a single command

Simplifying project setup and dependency management

## 🎯 Goal

The goal of this project is to build a full-stack bookmark management application that allows users to save and organize web pages for later use.

## Features

🔖 Save pages to revisit later

🗂️ Categorize bookmarks into groups

🤝 Share collections with other users

📥 Import bookmarks from external sources

🧩 Use a browser extension to save pages directly from an active tab

## 🧠 Tech Stack

Frontend: Angular

Backend: Express.js

Monorepo Tooling: Turborepo

Language: TypeScript
